# Guided-Activity-2-Interface-and-Inheritance-Practice

This folder now contains a working payment system example using:

- `PaymentMethod`
- `GCashPayment`
- `CardPayment`
- `Transaction`
- `OnlineTransaction`

## Run It

Use Node.js to run the JavaScript version:

```powershell
node payment.js
```

## Expected Output

```text
Transaction ID: TXN-001
Paid ₱500 using GCash.
```

## TypeScript Version

If you want to use the TypeScript file, run it through a TypeScript compiler or a TypeScript runtime first.
The source is in `payment.ts`.
